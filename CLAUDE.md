# Working on this project

## Second brain: read first, update always

`SECOND_BRAIN.md` is the project's memory.

1. **Read `SECOND_BRAIN.md` before doing anything else** in a session.
2. **Whenever the owner states a business requirement, business rule, definition,
   vocabulary, preference or decision, record it in `SECOND_BRAIN.md` in the same
   change** as any related code. Do not wait to be asked.
   - New vocabulary ("when we say X we mean field Y") goes in the **Business words**
     table. The app loads that table, so keep its three-column format.
   - Requirements go under **Business requirements** with the next R number.
   - Facts about the business or its data go under **Business knowledge**.
   - Choices and their reasons go in the **Decisions** table.
   - Add a line to the **Change log** and update "Last updated".
3. If a new instruction conflicts with something recorded, ask, then update the record.

## Non-negotiables (from the owner)

- Uploaded data never leaves the browser. No server, no analytics, no external API,
  no LLM. The only network requests are static files and the Pyodide engine from
  cdn.jsdelivr.net. Do not add other hosts (the Content-Security-Policy in
  `index.html` lists what is allowed).
- Answers come only from uploaded files. When words do not match, say so; never guess.
- Every answer, table and model result carries a plain-English "How I got this".
- Users never read or write SQL. Plain words everywhere; no analytics jargon in the UI.

## How it is built

Static site, no build step. Open `index.html` through any web server.

- `index.html`, `assets/app.js`, `assets/app.css`, `assets/charts.js`: the interface.
- `assets/worker.js`: starts Pyodide in a web worker and loads `engine/`.
- `engine/`: all logic, in Python. `api.py` is the only entry point the page calls.
  `store.py` SQLite, `ingest.py` file reading, `quality.py` data checks, `joins.py`
  link suggestions, `builder.py` tables and charts, `chat.py` question answering,
  `ml.py` machine learning.
- `vendor/`: pure-Python wheels loaded into Pyodide. `assets/vendor/`: Chart.js and the font.
- `sample-data/`: dummy files, generated by `tools/make_sample_data.py`.

The engine avoids pandas on purpose (smaller download, fewer version surprises):
SQLite for data, numpy and scikit-learn for machine learning.

## Checking changes

```bash
python tools/test_engine.py
```

```bash
python -m http.server 8000
```

Then open http://localhost:8000 and use "Try it with sample data". Test in the real
page after engine changes: Pyodide runs Python 3.12 with its own package versions.
